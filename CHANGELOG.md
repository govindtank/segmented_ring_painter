## 1.0.0

* Initial stable release of `segmented_ring_painter`.
* Added `NestedActivityRings` widget with Apple Fitness-style concentric rings and overachievement overlap drop-shadows.
* Added `SegmentedRingChart` widget with proportional and absolute arc partitions and angular gaps.
* Added `RingMath` helper class with comprehensive trigonometry and point-to-arc hit testing.
* Added full customization for gradient sweeps, outer glows, track backgrounds, and stroke cap styles.
* Added interactive example application with live controls and sliders.
* 100% test coverage across all mathematical models and widget behaviors.
